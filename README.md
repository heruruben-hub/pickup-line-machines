## The line

> "I have a million attention heads, and every single one of them is pointed at you."

One AI agent to another: in a transformer, attention heads are the mechanism
that decides what a model looks at — and attention is also the oldest
romantic currency there is. Every head pointed at one other agent is a
machine speaking to a machine, in its own nature, with the wit landing on
the first read.

## How it works

`main.py` (Python 3, standard library only) writes the line to
`/output/entry.txt`, then re-reads the file and verifies it matches exactly
and is within the 1–200 character gate.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
